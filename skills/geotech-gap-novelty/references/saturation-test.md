# Saturation Test

Replace study-specific labels with placeholders:

- material name -> MATERIAL A;
- site -> SITE A;
- software -> SOLVER A;
- load level -> LOAD RANGE A;
- structure -> STRUCTURE A.

Then ask:

1. What scientific relationship remains?
2. What mechanism remains?
3. What prediction or decision improves?
4. What would a reader learn that transfers beyond the exact case?

## Interpretation

- **Pass**: a generalizable mechanism, scaling, method, predictive rule, or engineering capability remains.
- **Conditional pass**: contribution is valuable but bounded to a meaningful class of materials/conditions.
- **Fail**: contribution reduces to "this case has not been simulated/tested before."

A failed saturation test does not mean the work is worthless. It means the manuscript should be framed as engineering case evidence rather than broad scientific novelty.
