# Novelty Framework

| Dimension | Core question | Strong evidence |
|---|---|---|
| Phenomenon | Is there a response/regime not previously established? | repeatable transition, threshold, spatial/temporal pattern |
| Mechanism | Does the study discriminate why the response occurs? | independent observables, competing-mechanism test, mechanics |
| Method | Can the study measure/derive/predict something not previously possible? | benchmark, error reduction, new observable, reproducibility |
| Evidence | Is evidence materially stronger or more direct? | field + lab, multi-scale, direct measurement, independent replication |
| Predictive model | Does a model explain/predict beyond fitted cases? | hold-out/independent validation, limiting cases, uncertainty |
| Engineering capability | Does it change a defensible decision? | design criterion, monitoring trigger, reliable prediction under defined scope |

## Parameter novelty warning

Changing one or more of these is not automatically scientific novelty:

- confining pressure;
- crack depth;
- pile diameter;
- tunnel depth;
- soil location;
- constitutive model name;
- software;
- number of cycles;
- surcharge range.

Parameter variation becomes stronger novelty when it reveals a regime boundary, mechanism transition, non-dimensional relation, failure envelope, or validated engineering consequence.
