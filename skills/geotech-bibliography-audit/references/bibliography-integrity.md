# Bibliography Integrity Rules

Separate structural consistency from scientific validity.

Structural failures:
- cited key missing from bibliography;
- unused bibliography entry;
- duplicate citekey;
- duplicate DOI;
- duplicate normalized title;
- malformed record boundaries.

Scientific-validity failures require other skills:
- wrong DOI for title -> `geotech-reference-verifier`;
- real source does not support claim -> `geotech-citation-fidelity`.

An orphan reference is not automatically an error when the target journal permits uncited bibliography sections; record the reason explicitly.
