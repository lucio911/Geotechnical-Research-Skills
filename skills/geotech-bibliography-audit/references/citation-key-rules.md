# Citation Key Rules

Citation keys are project identifiers, not bibliographic truth.

- Prefer stable keys once a manuscript is underway.
- Correcting a title or author should not gratuitously break every in-text citekey.
- If a key is changed, update all manuscript occurrences atomically.
- Detect key collisions separately from author-year rendering collisions.
- Record redirects when legacy keys must be retained for reproducibility.
