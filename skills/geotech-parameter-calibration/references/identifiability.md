# Parameter Identifiability Audit

Separate:

- **structural identifiability**: can ideal, noise-free observations uniquely identify parameters in principle?
- **practical identifiability**: do the available data constrain them sufficiently in practice?

Diagnostics include sensitivity rank, parameter correlations, profile likelihood/objective scans, bootstrap spread, repeated starts, posterior dependence where Bayesian calibration is used, and stability across data subsets.

Warning signs: bound-hitting parameters, very wide intervals, multimodality, strong compensating parameters, and similar predictions from materially different parameter sets.
