# Claim Ladder v0.4

| Level | Type | Typical wording | Minimum expectation |
|---|---|---|---|
| C1 | Description | X increased/decreased/localized | direct evidence |
| C2 | Quantified trend | X increased by... / threshold at... | defined metric + traceable values |
| C3 | Association | X increased concurrently with Y | multiple measured/modelled responses |
| C4 | Mechanistic consistency | pattern is consistent with mechanism M | mechanics + triangulated responses |
| C5 | Mechanistic/causal | M governs/drives/is responsible for... | competing explanations addressed + discriminating evidence |
| C6 | Generalization/engineering implication | parameter/criterion can be used to predict/design... | independent validation + transferability evidence |

## Language calibration

C3–C4 verbs:

- coincides with
- is accompanied by
- is consistent with
- suggests
- supports the interpretation that

C5 verbs require stronger evidence:

- drives
- governs
- controls
- causes
- is responsible for

C6 verbs require transferability:

- predicts
- provides a design criterion
- can be generalized to
- can be used for engineering assessment
