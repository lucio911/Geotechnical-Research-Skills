# Contour Plot Audit

Before using a contour as evidence, recover:

- variable/component;
- physical definition;
- unit;
- coordinate/sign convention;
- step/frame/load/time;
- contour range;
- whether ranges are identical across compared plots;
- deformation scale factor;
- mesh dependence/smoothing/averaging where relevant.

## Claims a contour can usually support

- location of high/low response;
- qualitative redistribution;
- symmetry/asymmetry;
- localization pattern;
- evolution of a spatial pattern if visualization settings are comparable.

## Claims requiring extracted metrics

- percentage increase/decrease;
- threshold/onset load;
- global stiffness/capacity change;
- crack-growth rate;
- failure criterion;
- general causal mechanism.

Pair a field plot with a line/point/integral metric whenever the manuscript makes a quantitative or mechanistic claim.
