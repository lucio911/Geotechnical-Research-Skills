# Mechanism vs Association

For a proposed mechanism M, create:

| Item | Question |
|---|---|
| Prediction | If M is true, what else should change? |
| Independent observable | Is that quantity measured/computed independently? |
| Timing/path | Does the sequence fit M? |
| Competing mechanism | What else could produce the same trend? |
| Discriminator | What result would separate M from the competitor? |
| Boundary | Under what states/loading should M cease or change? |

## Warning signs of mechanism inflation

- mechanism inferred from one response variable;
- mechanism name copied from literature without direct test;
- multiple correlated degradation metrics treated as independent confirmation;
- numerical localization described as physical damage without constitutive/experimental validation;
- temporal coincidence treated as causality.
