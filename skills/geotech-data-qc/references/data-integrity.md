# Data integrity rules

- Raw files are immutable.
- Assign persistent test/specimen/channel IDs.
- Record copy/export/software version where relevant.
- Store transformation code or equations.
- Never replace an observed value with an interpolated value without a flag.
- Keep exclusions as a mask/ledger rather than deleting the only copy.
- Record unit conversions explicitly.
- If manual edits are unavoidable, preserve before/after values and rationale.
