# Cyclic test QC

Check:

- first-cycle seating/transient;
- measured versus target amplitude;
- frequency stability;
- zero-crossing and peak detection;
- loading/unloading segmentation;
- actuator limit/clipping;
- accumulated residual displacement;
- phase/synchronization between force and displacement;
- specimen heating/drainage/rest effects;
- any change in controller settings.

Deleting the first N cycles must have a declared physical/data-quality reason, not merely improve the degradation curve.
