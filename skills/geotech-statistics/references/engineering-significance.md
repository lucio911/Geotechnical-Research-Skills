# Statistical vs Engineering Significance

For every statistically estimated effect report, where possible:

- physical magnitude and units;
- normalized magnitude relative to a meaningful baseline;
- uncertainty interval;
- comparison with measurement resolution/repeatability;
- comparison with a design/serviceability/failure threshold if justified;
- applicability conditions.

A small, precisely estimated effect can be statistically significant but engineering-negligible. A large uncertain effect can be engineering-concerning even when a small-sample test lacks power.
