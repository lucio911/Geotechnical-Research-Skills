# Repeated Measures in Geotechnical Tests

Repeated cycles, load stages, depths, time points, and sensors from one specimen share dependence.

Ask:

- what is the experimental unit?
- which observations are repeated within that unit?
- are specimens independent?
- is there an order/sequence effect?
- is a mixed/hierarchical model warranted?
- can the question be answered descriptively if n is too small for reliable hierarchical inference?

Pseudo-replication inflates apparent precision and must be avoided.
