# Geotechnical Journal Reference Checklist

Before submission check:

- target journal style/CSL identity;
- reference order (alphabetical / citation order);
- maximum authors before truncation;
- journal name abbreviation policy;
- article-number vs page-range handling;
- DOI representation;
- online-first/final-year policy;
- standards, reports, theses, datasets, and software formatting;
- non-English title/language/transliteration rules;
- consistency between in-text citation and bibliography rendering.

Use journal instructions as the final style authority when they conflict with generic examples.
