# Metadata vs Style

Metadata describes the work:
- authors and order;
- title;
- container/journal;
- year/date;
- volume/issue;
- pages/article number;
- DOI/URL;
- language/version/type.

Style controls presentation:
- punctuation;
- initials vs full names;
- author truncation;
- title capitalization rules;
- journal abbreviation;
- ordering;
- DOI/URL presentation;
- in-text author-date vs numeric rendering.

A style transformation must not silently change work identity.
