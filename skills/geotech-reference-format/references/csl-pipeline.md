# CSL Pipeline

Recommended pipeline:

1. verified source record;
2. canonical CSL-JSON;
3. selected CSL style + locale;
4. deterministic processor (citeproc or bibliography engine);
5. rendered in-text citation/bibliography;
6. style audit against journal instructions and sample article.

Record the CSL style identifier, style version/commit when possible, locale, processor, and rendering date for reproducibility.
