# Normalization Audit

For each normalized quantity record:

- numerator;
- denominator/reference value;
- physical reason for the reference;
- whether the reference is specimen-specific, first-cycle, initial-state, global, or fitted;
- whether the same reference is used across all groups;
- whether normalization introduces dependence or hides absolute magnitude.

Examples requiring explicit definitions: `G/G0`, `K_N/K_1`, `w/D`, `q/p_a`, `rp/D`, normalized crack depth, and percentage strain.
