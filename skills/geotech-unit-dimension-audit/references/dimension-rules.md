# Dimension Rules

Recommended base dimensions:

- length: L
- mass: M
- time: T
- force: F = M L T^-2
- stress/modulus: F L^-2
- strain: dimensionless
- angle: mathematically dimensionless but computational convention must be explicit

Rules:

- additive terms must have identical dimensions;
- equality requires identical dimensions on both sides;
- arguments of exp/log/trig should be dimensionless;
- a power-law coefficient generally carries units unless variables are normalized;
- fitted constants must not be assumed dimensionless by default.
