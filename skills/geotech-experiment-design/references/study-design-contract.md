# Experiment Contract

Record before testing:

- research question;
- primary hypothesis;
- competing explanation(s);
- experimental unit;
- manipulated factor(s) and levels;
- controls and reference condition;
- blocking/nuisance variables;
- material state and preparation;
- stress measure and consolidation path;
- drainage condition;
- loading history and sequence;
- measurements and derived variables;
- independent replicate count;
- QC criteria;
- predefined primary contrast;
- expected direction only if theory justifies it;
- falsification/decision criterion;
- applicability boundary.

A test matrix is not an Experiment Contract unless it explains what scientific distinction each group provides.
