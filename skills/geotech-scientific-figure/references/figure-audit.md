# Figure audit

## Scientific
Main claim; panel role; quantitative evidence; reference state; uncertainty; comparison fairness.

## Numerical contours
Variable/component; unit; same contour limits for comparison; deformation scale; load/step/frame; coordinate orientation; mesh visibility only if relevant; no qualitative threshold claims from color alone.

## Graphics
Axis labels/units; symbol consistency; line styles; font readability at final size; panel labels; legend order; significant figures; color-blind/grayscale legibility where required.

## Caption
Define abbreviations, loading cases, crack depths/locations, normalization, statistical descriptors, and any non-obvious processing.
