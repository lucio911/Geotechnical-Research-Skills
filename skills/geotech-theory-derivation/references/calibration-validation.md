## Identifiability checks

- parameter correlation;
- profile likelihood or sensitivity;
- bootstrap stability;
- multi-start fitting;
- nested-model comparison;
- whether parameter values remain stable across independent conditions.

## Validation hierarchy

1. in-sample fit — not validation;
2. held-out points from same condition — weak validation;
3. independent loading/stress/material condition — stronger;
4. independent dataset/laboratory/site — strong;
5. prospective/field prediction — strongest for engineering prediction.

Claim predictive capability only at a level supported by the validation hierarchy.
