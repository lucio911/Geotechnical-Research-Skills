# Derivation Audit v0.4

## A. Problem contract
- prediction target defined?
- scale/dimensionality defined?
- state/loading/drainage scope defined?
- falsification condition stated?

## B. Definitions
- coordinates/sign convention?
- stress measure?
- strain measure?
- units?
- reference/initial state?
- normalized-variable denominators?

## C. Equation classes
For each equation, classify: equilibrium / kinematics / constitutive / state evolution / boundary / empirical closure / definition / approximation.

## D. Closure
- number of unknowns versus independent equations?
- empirical closures identified?
- boundary/initial conditions sufficient?

## E. Dimensions and limits
- dimensions consistent?
- transcendental function arguments dimensionless?
- N=1 or t=0 behavior?
- zero-damage/unbroken state?
- N→∞ / large-deformation behavior?
- parameter bounds preserve physical admissibility?

## F. Evidence
- derivation source?
- calibration data?
- validation data independent?
- uncertainty/sensitivity?

## G. Wording
Does the manuscript call the model mechanics-derived, mechanism-informed, empirical, or predictive accurately?
