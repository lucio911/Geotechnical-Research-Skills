# Source Role Taxonomy

A citation should have an explicit scientific job.

- `context`: establishes engineering relevance or prevalence.
- `foundation`: original theory, definition, or method.
- `method-precedent`: justifies a test, model, metric, or analysis choice.
- `benchmark`: provides a dataset or response suitable for comparison.
- `trend-support`: independently reports the same bounded trend.
- `mechanism-support`: provides evidence relevant to the same physical mechanism.
- `contradictor`: reports a conflicting trend, mechanism, or interpretation.
- `boundary`: defines where a finding ceases to apply.
- `standard`: establishes a normative requirement; do not treat as research evidence.
- `novelty-comparator`: closest prior work against which novelty must be defended.

A topically relevant paper with no defined role should not automatically be cited.
