# Search Protocol

## Search ladder

Use separate query families rather than one oversized Boolean string.

1. Object + response.
2. Material + mechanism.
3. Loading/stress path + mechanism.
4. Method + response.
5. Boundary condition + response.
6. Contradictory mechanism or opposite trend.
7. Seminal author/title citation chasing.

## Search log fields

- search_id
- database/source
- date searched
- query
- filters
- results screened
- papers retained
- reason for refinement

## Geotechnical comparison axes

Material/state, effective stress, OCR/relative density, saturation, drainage, loading path, amplitude, frequency, cycle count, geometry, scale, interface condition, constitutive assumptions, response definition, and validation type.
