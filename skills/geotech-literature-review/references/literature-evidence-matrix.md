# Literature Evidence Matrix

Recommended columns:

| Field | Meaning |
|---|---|
| source_id | Stable identifier such as SRC-001 |
| citation | Verified bibliographic identity |
| study_type | experiment / field / numerical / analytical / review / standard |
| object | pile / tunnel / slope / soil element / etc. |
| material | soil/rock/material type |
| state | density, OCR, saturation, cementation, weathering, fabric |
| stress_condition | effective stress/state/stress path |
| drainage | drained/undrained/coupled/unspecified |
| loading | monotonic/cyclic/seismic/excavation/etc. |
| scale_geometry | specimen/model/field scale and key dimensions |
| response | measured/predicted variable |
| main_finding | bounded result stated by source |
| mechanism_author | mechanism claimed by authors |
| evidence_for_mechanism | direct / indirect / speculative |
| validation | independent experimental/field/numerical comparison |
| limitation | source-reported or evident scope boundary |
| role | background/method/support/contradiction/benchmark/etc. |
| current_claim_ids | claims this source may support |
| extraction_confidence | high/medium/low |

Never collapse distinct stress states or response definitions merely to fill a matrix cell.
