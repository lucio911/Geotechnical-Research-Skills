# Common Rejection Patterns in Geotechnical Research

## Novelty
- only changes a parameter range/material/location;
- nearest prior art not confronted;
- novelty claimed by method name rather than new capability.

## Mechanics
- causal mechanism inferred from co-variation;
- effective/total stress or drainage ambiguity;
- empirical variable given physical meaning without discriminating evidence.

## Experiment
- no repeatability/uncertainty for a trend comparable to scatter;
- boundary/scale effect ignored;
- insufficient state/material characterization.

## Numerical
- no independent validation;
- mesh/domain sensitivity absent for localization/failure claims;
- constitutive parameters fitted to the same response later called prediction;
- contour comparison uses inconsistent scales.

## Theory/model
- parameter proliferation;
- dimensional inconsistency;
- no limiting-case behavior;
- model called mechanism-based although functional form is empirical;
- no independent validation.

## Manuscript
- Introduction gap differs from actual contribution;
- figures do not map to central claims;
- Discussion repeats Results without mechanism test;
- Conclusions are broader than tested scope.
