# Contributing

Contributions should improve repeatability, scientific integrity, or geotechnical domain coverage.

A proposed skill should solve a distinct task and have a clear trigger boundary. Before adding a new skill, check whether the behavior belongs in an existing skill or a reference file.

For domain content, prefer stable mechanical principles and explicit source references. Do not reproduce copyrighted standards, manuals, or long passages from papers.

Every new skill should include at least one failure-mode section explaining what the agent must not infer or fabricate.
